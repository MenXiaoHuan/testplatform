# Playbook · 巡页（LLM 驱动的页面巡检）

## 1. 业务定位

巡页（Patrol）是平台内置的「无需编写测试代码」的页面巡检能力：配置一个入口页与任务描述，平台先为入口页做快照，再由规划模型生成探索用例，经预算与风险控制后执行，最后用视觉模型或 DOM 规则判定页面是否正常，并把截图、录屏、控制台日志与 DOM 归档。

适用场景：

- 新功能上线后，快速确认入口页关键交互是否可用
- 没有现成自动化用例时，对页面做一轮「模糊探索」
- 定时巡检核心页面，尽早发现白屏、报错、交互失效
- 为开发提供带截图/录屏/控制台的问题证据

与 UI 自动化任务的区别：

| 维度 | UI 自动化任务 | 巡页 |
|------|---------------|------|
| 用例来源 | 仓库中的 Playwright 测试代码 | 规划模型根据入口页快照生成 |
| 执行对象 | 代码仓库 + 分支 | 单个入口 URL |
| 判定方式 | 测试断言 | 视觉模型 + DOM/控制台规则 |
| 审批 | 无 | 写操作/危险操作需审批（可配置自动审批） |
| 主要产物 | 日志、Trace、视频、报告 | 用例录屏、步骤截图、控制台、DOM、发现项 |

## 2. 前置条件与权限

- `OPERATOR` / `ADMIN` 可创建/编辑/复制/删除巡页、配置模型、立即执行、审批与取消；`VIEWER` 只读。
- 执行前必须为巡页选择**规划模型**与**判定模型**，判定模型必须支持图片输入（Vision）。模型配置在「巡页 → 模型配置」中维护。
- 服务端需可访问目标页面地址；需要登录时在巡页中配置认证信息（Cookie / Token / Local Storage）。
- 产物写入 MinIO；模型日志为敏感信息，**仅超级管理员**可见。

## 3. 功能与操作说明

入口：空间菜单「UI 自动化 → 巡页」，路由 `/spaces/{spaceId}/patrol`。

### 3.1 巡页列表

页面工具栏在卡片头部，右侧为「模型配置」与「新建巡页」。

| 列 | 含义 |
|----|------|
| 名称 | 巡页名称 + 描述 |
| 规划 / 判定模型 | 当前巡页使用的两个模型 |
| 预算 | 时长、LLM Token、可见文本字符上限 |
| 总 Token 消耗 | 该巡页历史任务的 Token 消耗汇总 |
| 定时 | 「已开启」标签 + Cron；未开启显示「手动」 |
| 最近执行 | 最近一次任务创建时间 |
| 操作 | 执行 / 历史 / 编辑 / 复制 / 删除 |

列表每 3 秒自动刷新，用于观察运行中的任务。

### 3.2 新建 / 编辑巡页

| 分组 | 字段 | 说明 |
|------|------|------|
| 基础信息 | 名称 | 必填，空间内唯一，≤128 字符 |
| 基础信息 | 描述 | 可选，≤512 字符 |
| 基础信息 | 入口 URL | 必填，`http/https`，≤2048 字符 |
| 基础信息 | 浏览器 | `chromium` / `chrome` / `firefox` / `edge`，默认 `chromium` |
| 基础信息 | 运行模式 | 无头 / 有头，默认无头 |
| 基础信息 | 任务描述 | 告诉模型本次巡检关注什么，≤1024 字符 |
| 模型与预算 | 规划模型 | 必填，生成用例 |
| 模型与预算 | 判定模型 | 必填，必须支持图片输入 |
| 模型与预算 | 时长预算 | 1~60 分钟，默认 15 分钟 |
| 模型与预算 | Token 预算 | 10000~1000000，默认 300000 |
| 模型与预算 | 页面文本上限 | 100~100000 字符，默认 1800 |
| 模型与预算 | 滚动扫描 | 默认开启，扫描页面可视区外的可交互元素 |
| 模型与预算 | 录制视频 | 默认开启，每条用例独立录屏 |
| 认证与授权 | 认证方式 | `NONE` / `COOKIE` / `TOKEN` / `LOCAL_STORAGE` |
| 认证与授权 | 认证内容 | Cookie、Bearer Token 或 Local Storage JSON，密文保存 |
| 认证与授权 | 自动批准写操作 | 默认关闭；开启后写操作用例无需人工审批 |
| 认证与授权 | 自动批准危险操作 | 默认关闭；删除等不可逆操作需显式开启 |
| 定时 | 启用定时 | 开启后按 Cron 自动创建任务 |
| 定时 | Cron | Spring 6 段表达式，例如每天 02:30 为 `0 30 2 * * *` |

「复制」会打开新建弹窗并带入原巡页配置，名称自动加「副本」，保存后生成新的巡页。

### 3.3 模型配置

「模型配置」抽屉维护当前空间的巡页模型：

- 列表展示名称、Base URL、模型 ID、能力标签（视觉 / 工具调用 / JSON 输出）、启用状态与最近测试结果。
- 支持新建、编辑、删除、测试连通性。删除被巡页引用的模型会导致该巡页无法规划/判定，删除后需回到巡页重新选择模型。
- 新建时 API Key 必填；编辑时留空表示保持原 Key。
- 能力参数默认勾选「支持图片输入」「支持工具调用」「支持 JSON 输出」，按模型实际情况调整；判定模型必须保留「支持图片输入」。
- Base URL 默认不填，需填写 OpenAI 兼容端点（如 `https://api.openai.com/v1`）。

### 3.4 立即执行

点击「执行」会创建一次手动任务。触发前服务端校验：

1. 巡页已配置规划模型与判定模型；
2. 该巡页没有处于活动状态的任务；
3. 平台并发未达到上限（默认 2）。

校验失败会直接提示原因，不会创建任务。创建成功后自动打开该巡页的执行历史。

### 3.5 执行历史

| 区域 | 内容 |
|------|------|
| 汇总卡片 | 平均 Token、平均元素覆盖率、平均耗时（仅统计已结束任务） |
| 表格 | 状态、用例通过/总数、耗时、Token、覆盖率、触发方式、创建时间、操作 |
| 操作 | 详情 / 取消（活动任务）/ 删除（已结束任务） |
| 分页 | 右下角，`total + sizes + prev/pager/next`，默认 10 条/页 |

删除任务会同时清理该任务的快照、用例录屏、步骤截图、控制台与 DOM。

### 3.6 任务详情

抽屉标题为「巡页任务」，包含三个 tab：

1. **概览**：状态、触发方式、场景与入口、耗时、结果说明；统计卡片（用例通过、元素覆盖、失败用例、LLM Token、保留至）；执行信息（审批人/审批时间、开始/结束、当前阶段）与任务描述、模型快照。
2. **用例**：按「全部 / 成功 / 失败」筛选；每个用例展示意图、期望、判定原因、风险等级；展开后可看录屏与步骤明细（动作、目标、风险与授权、结果、截图、信息），以及最终截图、控制台日志、DOM。
3. **模型日志**：仅超级管理员可见。按阶段展示 `PLAN`（规划）、`COVERAGE`（覆盖率补全）、`JUDGE`（判定）的模型、用途、状态、Token、耗时与错误；可展开查看完整系统/用户上下文和模型原始输出。

活动中的任务每 2 秒刷新详情；任务结束后停止刷新。

### 3.7 审批

任务停在「待审批」时，详情顶部出现审批卡片：

| 操作 | 效果 |
|------|------|
| 批准并执行 | 授权写操作；「允许危险操作」开关打开时才授权删除等不可逆操作 |
| 全部拒绝（仅只读） | 只执行只读用例，写/危险用例不执行 |

审批请求会记录审批人、审批时间与授权的用例 ID；审批后任务继续执行，无需重新创建。

## 4. 关键规则与限制

### 4.1 任务状态

| 状态 | 前端文案 | 含义 |
|------|----------|------|
| `QUEUED` | 待执行 | 已创建，等待执行 |
| `RUNNING` | 执行中 | 正在快照、规划、执行或判定 |
| `WAITING_APPROVAL` | 待审批 | 用例已生成，等待人工授权 |
| `COMPLETED` | 已完成 | 执行结束并完成判定（可能带降级） |
| `FAILED` | 失败 | 准备/快照/执行阶段失败，或恢复逻辑判定失败 |
| `CANCELED` | 已取消 | 用户取消并已停止 |

### 4.2 执行阶段

`PREPARING`（安装依赖/准备执行环境）→ `SNAPSHOTTING`（入口页快照）→ `PLANNING`（生成用例与覆盖率补全）→ `WAITING_APPROVAL`（可选）→ `EXECUTING`（逐用例执行）→ `JUDGING`（视觉/规则判定）→ `FINISHED`（归档与收尾）。

### 4.3 预算与降级

| 项 | 默认值 / 规则 |
|----|---------------|
| 时长预算 | 15 分钟；超时后停止继续执行，已产生的用例结果仍归档 |
| Token 预算 | 300000；规划、覆盖率补全、判定共同消耗 |
| 预算耗尽 | 任务标记「降级」，并记录停止原因；判定退回 DOM + 控制台规则 |
| 规划输出 | 单次最多约 4500 Token；最多 8 步/用例；动作有白名单 |
| 判定输出 | 单次最多约 1800 Token；需要入口页/失败步骤截图 |
| 模型调用 | 单次超时 90 秒；最多尝试 2 次；图片长边压缩至 1568、JPEG 质量 0.8 |
| 环境准备 | 依赖安装超时 300 秒；入口页快照超时最多 300 秒 |
| 页面操作 | 页面加载 20 秒；单步动作 5 秒 |
| 模型最大输出 | 模型配置中 256~32768，界面默认 4500 |

降级（`degraded=true`）表示任务仍完成，但部分模型环节未按预期工作：无可用模型、Token 不足、模型调用失败或输出无法解析。降级原因与阶段状态在模型日志中可查。

### 4.4 风险与审批

- 用例风险等级：`READ` < `WRITE` < `AUTH` < `DESTRUCTIVE`；用例的 `worstRisk` 取步骤最高风险。
- 只含 `READ` 的用例自动通过；存在 `WRITE` / `AUTH` / `DESTRUCTIVE` 时任务进入待审批。
- 巡页开启「自动批准写操作」/「自动批准危险操作」后，对应风险无需人工审批。
- 审批只能针对「待审批」任务；已授权用例按 ID 校验，不能审批其他任务的用例。

### 4.5 执行与判定

- 每次执行从入口页开始，只对入口页做快照与元素覆盖统计；跳转用于验证落点。
- 每条用例使用独立浏览器上下文并录屏；用例结束后额外等待 3 秒再结束录制，保留收尾画面。
- 用例执行失败（`FAILED`）直接判定失败并生成 P0 交互发现项。
- 模型判定基于截图 + 页面信息；模型不可用或输出不合法时退回规则判定：
  - 有失败步骤 → 失败，P0；
  - 控制台有错误 → 失败，P1；
  - 其他 → 通过。
- 发现项严重级别 `P0` / `P1` / `P2`；类型包括 `BLOCKER`、`INTERACTION`、`DISPLAY`、`COPY`、`CONSISTENCY`。

### 4.6 定时与并发

| 项 | 规则 |
|----|------|
| 调度扫描 | 每 60 秒扫描到期巡页，创建定时任务并计算下次运行时间 |
| 调度跳过 | 未配置模型、同巡页已有活动任务、平台并发已满时跳过本次 |
| 下次运行时间 | 无论本次成功与否都会推进，避免同一时刻重复触发 |
| 平台并发 | 默认 2 个巡页任务并行；超出时手动执行直接提示，定时执行跳过 |
| 取消 | 协作式取消：置取消标记，当前步骤结束后停止 |
| 服务重启 | 启动时把中断的活动任务标记失败；「待审批」任务保留，可继续审批 |

### 4.7 保留策略

| 项 | 规则 |
|----|------|
| 任务保留 | 默认 90 天，到期删除任务记录与全部证据 |
| 清理时间 | 每天 02:30（`platform.patrol.retention-cron`，默认 `0 30 2 * * *`） |
| 清理批量 | 每次最多 50 个任务 |
| 删除巡页 | 有活动任务时禁止删除；删除巡页会清理其历史任务与证据 |

## 5. 典型流程

### 5.1 首次配置并执行

1. 进入「巡页 → 模型配置」，新建规划模型与判定模型（判定模型勾选视觉能力），测试连通性。
2. 新建巡页：填入口 URL、任务描述，选择规划/判定模型，按需调整预算与认证。
3. 点「执行」，确认任务进入「执行中」。
4. 若任务进入「待审批」，在详情中查看将要执行的写/危险用例，选择「批准并执行」或「全部拒绝」。
5. 执行完成后查看用例与发现项，下载录屏/截图给开发。

### 5.2 定时巡检

1. 在巡页中开启定时并填写 Cron（如 `0 30 2 * * *`）。
2. 确认巡页模型可用、预算合理。
3. 次日从「历史」查看任务；定时任务被跳过时检查活动任务与平台并发。

### 5.3 排查一次降级任务

1. 打开任务详情，看概览中的结果说明与「降级」标记。
2. 切到「模型日志」（超级管理员），确认是 `PLAN`、`COVERAGE` 还是 `JUDGE` 阶段降级。
3. 按状态区分：`SKIPPED` 多为预算不足或未配置；`FAILED` 看错误信息与原始输出；`DEGRADED` 看是否退回规则判定。
4. 若是 Token 不足，调大 Token 预算或收敛任务描述；若是模型调用失败，先在模型配置中测试连通性。

## 6. 常见问题

| 现象 | 排查 |
|------|------|
| 点「执行」直接提示未配置模型 | 巡页必须选择规划模型与判定模型；先到「模型配置」创建并选择 |
| 提示已有任务在执行 | 同一巡页同一时间只允许一个活动任务；等结束或取消后再执行 |
| 提示并发已满 | 平台默认 2 个并行巡页任务；等待其他任务结束 |
| 任务卡在「待执行」 | 执行线程繁忙或服务刚重启；查看服务日志与队列 |
| 一直停在「执行中」 | 看当前阶段：准备/快照阶段多为环境或网络；执行阶段看用例与录屏 |
| 进入「待审批」但没有审批按钮 | 只有「待审批」状态可审批；确认任务未结束、非取消 |
| 判定结果全是规则判定 | 查看模型日志：可能模型未配置、调用失败、Token 不足或输出无法解析 |
| 覆盖率偏低 | 页面元素在折叠区或 iframe 中；开启滚动扫描，必要时调大页面文本上限让模型看到更多元素信息 |
| 录屏缺失 | 巡页关闭了录屏，或用例未开始执行；在巡页配置中开启「录制视频」 |
| 产物下载 403 / 过期 | 证据通过预签名 URL 下载，过期后重新打开任务详情获取新链接 |
| 定时任务没有触发 | Cron 是否为 6 段；巡页是否开启定时；是否因活动任务/并发被跳过 |
| 历史任务消失 | 任务按 90 天保留，到期由每日 02:30 清理任务与证据 |
| 看不到「模型日志」tab | 仅超级管理员可见，普通管理员也看不到 |
| 删除巡页失败 | 该巡页仍有活动任务；先取消或等待结束 |
