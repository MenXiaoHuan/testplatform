# Playbook · 模型评测 - 评测集（Dataset）

## 1. 业务定位

评测集是离线批跑的输入集合：一条用例包含输入、参考答案、判定关键词与参考上下文。评测集可版本化、可打场景标签，同一份用例可被多次运行复用，从而让不同 Prompt 版本 / 不同 Agent 的结果可比。

适用场景：

- 维护业务回归集（客服问答、意图识别、文档问答）
- 导入公开数据集（MMLU / HumanEval / GSM8K / TruthfulQA 等内置集）
- 给 LLM-as-Judge 提供评分上下文

## 2. 前置条件与权限

- 空间成员可查看；新增 / 编辑 / 导入建议由评测负责人操作。
- 内置评测集随平台启动同步，作为只读基线。

## 3. 功能与操作说明

| 功能 | 操作路径 | 说明 |
|------|----------|------|
| 评测集列表 | `/spaces/{id}/evaluation/datasets` | 左侧评测集，右侧用例 |
| 新建评测集 | 「+ 新建」/「+ 新建评测集」 | 填名称、版本、描述、标签、推荐目标类型 |
| 新增用例 | 右侧「+ 新增用例」 | 单条录入 |
| 导入 JSONL | 「导入 JSONL」 | 选择 `.jsonl` 文件批量导入 |
| 查看用例 | 用例行「查看」 | 只读查看完整字段 |
| 编辑 / 删除用例 | 用例行「编辑」「删除」 | 内置评测集的用例受保护 |
| 删除评测集 | 左栏「×」 | 删除前确认没有运行引用 |

### 字段说明

| 字段 | 说明 |
|------|------|
| 评测集名称 | 最多 256 字符 |
| 版本 | 如 `v1`，便于对照 |
| 描述 | 说明测什么、适用场景 |
| 场景标签 | 回车添加，如 数学 / 代码 / 中文 |
| 推荐目标类型 | `LLM_API` / `HTTP_AGENT` / `BUILTIN_AGENT` |
| 输入 | 用户输入 / 任务描述 / Prompt 变量内容，必填 |
| 参考答案 | 期望输出，可留空（此时依赖 Judge 或规则评分） |
| 判定关键词 | 关键词匹配评分器优先使用 |
| 参考上下文 | 供 Judge 参考的文档片段或评分说明 |

### JSONL 导入格式

每行一个 JSON 对象，至少包含输入字段；可选参考答案、关键词、参考上下文。导入失败会返回失败行号与原因，已成功的行不回滚。

## 4. 关键规则与限制

| 规则 | 说明 |
|------|------|
| 名称唯一 | 同一空间内评测集名称唯一 |
| 分页上限 | 用例列表 `size ≤ 100` |
| 内置评测集 | 只读基线：不可删除、不可导入覆盖；升级随迁移脚本同步 |
| 导入校验 | JSONL 必须逐行合法 JSON，缺必填字段的行会被拒绝 |
| 用例量 | 大批量导入建议拆分文件，避免单次请求超时 |
| 删除 | 已被运行引用的评测集建议保留，删除后历史运行无法回溯用例 |

## 5. 典型流程：建一个业务回归集

1. 新建评测集，填写名称、版本与描述，打上 `中文` / `业务` 标签。
2. 先手工新增 3~5 条代表性用例，确认字段填写方式。
3. 批量用例整理成 JSONL，按「导入 JSONL」上传。
4. 在「离线任务」启动评测，选择该评测集与目标 Agent。
5. 根据结果补充「判定关键词 / 参考上下文」，提升评分稳定性。

## 6. 常见问题

| 现象 | 排查 |
|------|------|
| 导入报错 | 检查 JSONL 是否每行一个对象、是否缺「输入」 |
| 内置评测集按钮禁用 | 内置集为只读基线，属预期行为 |
| 评测结果全是 0 分 | 用例缺参考答案且评分器需要参考答案 |
| 关键词评分不生效 | 评分器中未选择关键词匹配，或关键词字段为空 |
| 用例列表加载慢 | 单评测集用例过多，建议拆分评测集 |
