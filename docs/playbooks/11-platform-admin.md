# Playbook · 平台运维 - 用户管理与注册开关

## 1. 业务定位

「平台运维」面向平台级管理，而不是单个空间：超级管理员在这里管理全平台账号（查看、编辑、重置密码、删除），并控制登录页是否开放自助注册。注册开关从配置文件迁移到数据库后，修改即时生效，无需重启服务。

适用场景：

- 关闭自助注册，改为管理员统一建号
- 排查某个账号异常（禁用、重置密码）
- 清理离职人员账号
- 临时开放注册让新成员自助注册

## 2. 前置条件与权限

- **仅超级管理员可见**：菜单「平台运维 → 用户管理」由 `authStore.isSuperAdmin` 控制，路由 `superAdminOnly`，后端接口二次校验 `superAdmin()`，非超管返回 403。
- 超级管理员身份由数据库字段 `platform_user.is_super_admin` 决定。

## 3. 功能与操作说明

页面路径：`/spaces/{id}/users`（入口固定在当前空间菜单，但操作对象是全平台用户）。

| 功能 | 操作 | 说明 |
|------|------|------|
| 用户列表 | 页面主体 | 列：ID、用户（头像 + 昵称 + 用户名）、角色、状态、注册时间、更新时间 |
| 搜索 | 顶部输入框 + 「查询」 | 按用户名或昵称模糊搜索，回车即查询 |
| 允许自助注册 | 右上角开关 | 切换前弹出确认，展示「当前状态 → 切换后」 |
| 查看用户 | 行内「查看」 | 头像、昵称、用户名、角色、状态、最近空间、时间信息 |
| 编辑用户 | 行内「编辑」 | 修改昵称（≤10 字符）与启用状态 |
| 重置密码 | 「更多 ▾ → 重置密码」 | 输入新密码，前端 RSA 加密后提交 |
| 删除用户 | 「更多 ▾ → 删除」 | 清理空间成员关系与登录会话 |

## 4. 关键规则与限制

| 规则 | 说明 |
|------|------|
| 仅超管 | 前后端双重校验，普通空间 ADMIN 也看不到该菜单 |
| 昵称 | 最多 10 个字符，全平台唯一 |
| 密码 | 至少 8 位，且包含字母和数字；传输前 RSA 加密 |
| 不能禁用超管 | 禁用超级管理员账号返回「不能禁用超级管理员账号」 |
| 不能禁用自己 | 当前登录账号不可禁用 |
| 不能删除超管 | 删除超级管理员账号返回「不能删除超级管理员账号」 |
| 不能删除自己 | 当前登录账号不可删除 |
| 删除影响 | 一并清理 `space_member`、`user_session` 等关联数据，不可恢复 |
| 注册开关 | 写入 `platform_setting.registration_enabled`，即时生效；`.env` 的 `PLATFORM_REGISTRATION_ENABLED` 仅作默认值 |
| 审计 | 编辑、重置密码、删除、切换注册开关均写 `platform_audit_log` |

## 5. 典型流程：关闭自助注册并统一建号

1. 超管进入「用户管理」，把「允许自助注册」关闭，确认弹窗中核对状态变化。
2. 登录页刷新后不再展示注册入口（已登录用户不受影响）。
3. 新成员由超管创建后通知本人登录（或临时开启注册让其自助注册）。
4. 离职人员用「更多 → 删除」清理，确认其空间关系与会话被移除。

## 6. 常见问题

| 现象 | 排查 |
|------|------|
| 菜单里没有「用户管理」 | 当前账号不是超管（检查 `is_super_admin`） |
| 开关点了但登录页仍有注册入口 | 确认保存成功提示；刷新登录页；检查 `platform_setting` 值 |
| 无法禁用某账号 | 该账号是超管或就是当前登录账号 |
| 无法删除某账号 | 同上；超管与自身账号均受保护 |
| 重置密码后旧密码仍可登录 | 旧会话仍有效；让该用户重新登录或清理 `user_session` |
| 角色标签显示异常 | 见前端表格约定：角色列固定宽度 + 标签不换行 |
