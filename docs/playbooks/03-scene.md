# Playbook · UI 自动化 - 场景管理

## 1. 业务定位

场景（Scene）是「一次测试执行」的配置模板：选哪个仓库、哪个分支、跑哪些用例、用什么浏览器、注入哪些环境变量、是否定时执行。任务（Task）由场景触发产生，同一场景可以反复执行。

适用场景：

- 把仓库中的测试项目拆成多个可独立执行的场景（冒烟 / 回归 / 单模块）
- 配置每日定时回归
- 用不同浏览器或环境变量跑同一套用例

## 2. 前置条件与权限

- 空间角色 `OPERATOR` / `ADMIN` 可创建、编辑、复制、删除场景；`VIEWER` 只读。
- 至少存在一个启用状态的仓库。

## 3. 功能与操作说明

| 功能 | 操作路径 | 说明 |
|------|----------|------|
| 场景列表 | `/spaces/{id}/scenes` | 展示场景名称、所属仓库、执行模式、最近执行 |
| 新增场景 | 右上角「新增场景」 | 打开表单弹窗 |
| 编辑 | 行内「编辑」 | 修改配置，不影响历史任务记录 |
| 复制 | 行内「复制」 | 以当前配置快速创建相似场景 |
| 删除 | 行内「删除」 | 删除后不再可触发；历史任务保留 |
| 查看任务 | 行内「查看任务」 | 进入该场景的任务列表 |
| 立即执行 | 场景任务页「执行当前场景」 | 手动创建一个任务 |

### 场景表单字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 场景名称 | 是 | 空间内唯一 |
| 场景描述 | 否 | 业务说明，便于团队识别 |
| 所属仓库 | 是 | 仅可选择启用状态的仓库 |
| 分支 | 是 | 默认取仓库的默认分支 |
| 测试选择器类型 | 是 | 按文件 / 按标题 / 按标签等，决定下面的匹配值含义 |
| 匹配值 | 视选择器 | 如测试文件路径、用例标题、标签 |
| 浏览器 | 是 | 如 chromium / firefox / webkit |
| 环境变量 JSON | 否 | 注入 Runner 的环境变量，必须为合法 JSON |
| 启用定时 | 否 | 打开后填写 Cron 表达式 |
| Cron 表达式 | 定时开启时必填 | 秒级 6 段表达式（如 `0 0 2 * * ?`），按 Spring `CronExpression` 解析 |

## 4. 关键规则与限制

| 规则 | 说明 |
|------|------|
| 名称唯一 | 同一空间内场景名称唯一 |
| 仓库可用性 | 仓库不存在或已停用时拒绝保存 |
| Cron 合法性 | 保存时解析 Cron，非法表达式直接报错 |
| 调度扫描 | 调度线程每 60 秒扫描一次到期场景，按 `nextRunAt` 触发 |
| 幂等 | 同一场景同一时间点只生成一个任务，避免重复触发 |
| 调度事件 | 定时触发会产生调度事件记录，失败可手动重试 |
| 删除 | 删除场景不影响已产生的任务与产物，但后续无法再触发 |

## 5. 典型流程：配置每日凌晨回归

1. 在「场景管理」新增场景，选择回归测试仓库与 `main` 分支。
2. 测试选择器选择「按标签」，匹配值填 `@regression`。
3. 浏览器选择 `chromium`，按需补充环境变量 JSON。
4. 打开「启用定时」，填写 `0 0 2 * * ?`（每天 02:00）。
5. 保存后确认列表「执行模式」显示为定时。
6. 次日检查任务列表是否按预期产生任务；异常时在调度事件中查看失败原因并重试。

## 6. 常见问题

| 现象 | 排查 |
|------|------|
| 保存报「仓库不存在或已停用」 | 去仓库管理启用仓库，或改选其他仓库 |
| 定时未触发 | 检查 Cron 表达式、`nextRunAt`、服务端调度是否启用 |
| 同一时间触发两次 | 检查是否配置了重复场景；调度层已有幂等，重复场景会各自产生任务 |
| 场景执行选不到用例 | 检查选择器类型与匹配值是否与仓库内测试结构一致 |
| 环境变量不生效 | 确认是合法 JSON，且键名与测试代码读取方式一致 |
