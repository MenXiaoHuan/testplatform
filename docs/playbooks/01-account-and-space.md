# Playbook · 账号、空间与权限

## 1. 业务定位

平台以「空间（Space）」为隔离单位。一个空间代表一个团队 / 项目，所有仓库、场景、任务、评测数据都挂在空间下。账号体系负责身份认证，空间体系负责「谁能看到什么、谁能操作什么」。

适用场景：

- 新成员注册并加入团队空间
- 空间管理员审批加入申请、维护成员角色
- 超级管理员跨空间排障与运维

## 2. 前置条件与权限

| 角色 | 能力 |
|------|------|
| 未登录访客 | 仅可访问登录页；注册入口是否可见取决于「自助注册开关」 |
| VIEWER | 只读：可查看空间内的仓库、场景、任务与评测结果 |
| OPERATOR | 可操作：创建 / 编辑仓库与场景、触发任务、管理评测资源 |
| ADMIN | OPERATOR 全部能力 + 空间审批（通过 / 拒绝加入申请） |
| 超级管理员 | 所有空间视为 ADMIN，可在空间广场进入、编辑、删除任意空间，并可进入「用户管理」 |

> 角色取值为 `ADMIN` / `OPERATOR` / `VIEWER`，不要与 `DEVELOPER`、`OBSERVER` 等旧叫法混用。

## 3. 功能与操作说明

### 3.1 登录与注册

| 功能 | 操作路径 | 说明 |
|------|----------|------|
| 登录 | `/login` | 输入用户名 + 密码；密码在前端用 RSA 公钥加密后传输 |
| 自助注册 | `/login` 页注册入口 | 仅在开关开启时可见；注册成功后进入「设置昵称」 |
| 设置昵称 | `/setup-nickname` | 首次登录且昵称为空时强制跳转；昵称全平台唯一，最多 10 个字符 |
| 退出登录 | 右上角用户菜单 | 清除服务端会话与本地登录态 |

注册完成后系统自动创建该用户的个人空间，并把本人加入为 `ADMIN` 成员。

### 3.2 空间广场与加入空间

| 功能 | 操作路径 | 说明 |
|------|----------|------|
| 浏览空间 | `/home` | 展示平台内空间、所有者、当前角色与待审批申请 |
| 进入空间 | 行内「进入」 | 仅对自己已加入的空间可用 |
| 编辑 / 删除空间 | 行内「编辑」「删除」 | 空间所有者或超级管理员可见；删除会级联清理空间内数据 |
| 申请加入 | `/spaces/{id}/no-access` | 填写申请理由与期望角色，等待空间 ADMIN 审批 |

### 3.3 空间审批

| 功能 | 操作路径 | 说明 |
|------|----------|------|
| 查看申请 | `/spaces/{id}/access-requests` | 仅空间 ADMIN 可见 |
| 通过申请 | 行内「通过」 | 按申请中的角色加入空间成员 |
| 拒绝申请 | 行内「拒绝」 | 记录拒绝状态，申请人可重新申请 |

## 4. 关键规则与限制

| 规则 | 说明 |
|------|------|
| 密码强度 | 至少 8 位，且同时包含字母与数字 |
| 会话 | Cookie `platform_session`，HttpOnly；滑动过期，默认 14 天 |
| 昵称 | 最多 10 个字符，全平台唯一；用于界面展示与审计操作人 |
| 用户名 | 全平台唯一；注册后不可修改 |
| 注册开关 | 由超级管理员在「用户管理」切换，持久化到数据库；`.env` 中的 `PLATFORM_REGISTRATION_ENABLED` 仅作为默认值 |
| 重复申请 | 已存在 PENDING 申请时不可重复提交 |
| 权限校验 | 后端按 `space_id` 强制校验成员关系；前端菜单与路由守卫只是体验层，不作为安全边界 |

## 5. 典型流程：新成员加入团队空间

1. 超级管理员在 `/spaces/{id}/users` 打开「允许自助注册」，或由管理员代建账号。
2. 新成员在登录页注册 → 设置昵称 → 自动获得个人空间。
3. 新成员在空间广场找到目标空间，点击「申请加入」，选择角色并填写理由。
4. 目标空间 ADMIN 在「空间审批」通过申请。
5. 新成员刷新后可在广场进入该空间，侧边栏按角色展示模块。

## 6. 常见问题

| 现象 | 排查 |
|------|------|
| 登录页看不到注册入口 | 超级管理员确认「允许自助注册」为开启状态 |
| 登录后一直跳到设置昵称 | 账号昵称为空或长度超限，补充昵称即可 |
| 进入空间提示「没有该空间的访问权限」 | 尚未加入空间，走「申请加入」流程 |
| 有空间但看不到「空间审批」 | 当前空间角色不是 ADMIN |
| 看不到「用户管理」 | 仅超级管理员可见，普通管理员不可见 |
