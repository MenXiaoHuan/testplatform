# 模型评测：Prompt、Target、Dataset、离线与在线

## 1. 模块关系

```
Prompt 托管（提示词按 key + 版本管理）
      ↓ ACTIVE 版本
被评目标 Target（LLM_API / HTTP_AGENT / BUILTIN_AGENT）
      ↓
评测集 Dataset（输入 + 参考答案 + 关键词 + 参考上下文）
      ↓
离线评测 Offline Run（批量调用 + 评分 + 汇总）
      ↓
在线监控 Online Monitor（真实流量 Trace + 低分巡检）
```

---

## 2. Prompt 托管

### 2.1 作用

把提示词从代码中抽出来，按「key + 版本」集中管理。线上业务通过拉取当前 `ACTIVE` 版本使用；评测与 A/B 实验引用同一份版本，改 Prompt 不需要改代码、不需要重新发版。

### 2.2 字段

| 字段 | 说明 |
|------|------|
| 名称 | 最多 256 字符 |
| 类型 | 业务分类，如 system / 业务场景提示词 |
| 版本号 | 如 `v1`、`v2`，同一 key 内唯一 |
| 变更说明 | 最多 1024 字符 |
| 消息体 | `system` / `user` / `assistant` 多段组合，支持变量占位符 |
| 变量 | 可自动提取或手工维护 |

### 2.3 状态机与规则

| 规则 | 说明 |
|------|------|
| 状态 | `DRAFT` → `ACTIVE` → `DEPRECATED` |
| 唯一 ACTIVE | 同一 key 同一时间只允许一个 `ACTIVE` |
| 激活 | 激活新版本时，旧 `ACTIVE` 自动转为 `DEPRECATED` |
| 编辑限制 | 只有 `DRAFT` 可编辑；`ACTIVE` / `DEPRECATED` 只读 |
| 拉取 | 外部按 key 拉取当前 `ACTIVE` 版本，支持 ETag 304 协商缓存 |
| 版本冲突 | 并发激活返回 `PROMPT_VERSION_CONFLICT`（409） |
| Trace 关联 | 拉取时记录版本信息，可回溯到具体 Prompt 版本 |
| 删除 | 删除 key 会移除全部版本；线上仍在拉取的业务需先切走 |

### 2.4 典型流程：发布一版新 Prompt

1. 在已有 key 下新建版本，填写变更说明与消息内容。
2. 保存为 `DRAFT`，用评测集跑一次离线评测或 A/B 对照。
3. 确认效果后「激活」，该版本变 `ACTIVE`，旧版本自动废弃。
4. 业务下一次拉取即拿到新版本；有 ETag 缓存时按缓存策略刷新。
5. 出问题可重新激活上一版本，实现快速回滚。

### 2.5 常见问题

| 现象 | 排查 |
|------|------|
| 无法编辑版本 | 版本不是 `DRAFT`；先复制为新版本再改 |
| 激活失败 409 | 并发激活冲突，刷新后重试 |
| 拉取不到内容 | key 不存在或没有 `ACTIVE` 版本 |
| 业务侧仍拿到旧内容 | 客户端缓存了 ETag，按 304 逻辑刷新或清缓存 |
| Trace 看不到 Prompt 版本 | 业务调用未携带 traceparent 或未配置 Langfuse |

## 3. 被评目标（Target）

### 3.1 作用

统一建模被测对象。无论被测的是大模型 API、自建 HTTP Agent，还是平台内置 Agent，都通过同一套 Target 配置接入，复用评测集、评分器、离线批跑与在线监控。

### 3.2 三种类型

| 类型 | 适用 | 关键配置 |
|------|------|----------|
| `LLM_API` | OpenAI 兼容的模型接口 | Base URL、模型名、API Key、请求路径、Temperature、Max Tokens |
| `HTTP_AGENT` | 自建 Agent 服务 | 离线 Endpoint、请求方法、答案 JSONPath、请求头、请求体模板 |
| `BUILTIN_AGENT` | 平台内置 Agent | 选择内置 Agent key |

`HTTP_AGENT` 的离线 Endpoint 留空时，只能做在线 Trace，不能参与离线评测。

### 3.3 规则与限制

| 规则 | 说明 |
|------|------|
| 名称唯一 | 同一空间内 Target 名称唯一 |
| 能力区分 | 无离线 Endpoint 的 `HTTP_AGENT` 不能离线评测 |
| SSRF 防护 | Endpoint / Base URL 必须通过 SSRF 校验，内网地址可能被拒绝 |
| 健康检查 | 具备离线调用能力的 Target 可测试，失败返回具体错误 |
| 状态 | 默认 `ACTIVE`；停用后不能新建评测运行，历史结果保留 |
| 敏感配置 | API Key / Header 支持 `REF:ENV_NAME`，从服务端环境变量读取 |
| 统一类型 | 外部 Agent 统一落为 `HTTP_AGENT`，在线与离线共用同一个 targetId |
| Trace 密钥 | 接入 Trace 时生成 SDK 密钥，轮换后旧密钥立即失效 |

### 3.4 常见问题

| 现象 | 排查 |
|------|------|
| 测试失败 401/403 | 鉴权头缺失或 `REF:` 引用的环境变量不存在 |
| 测试失败 SSRF | Endpoint 指向内网地址，被安全策略拒绝 |
| 离线评测选不到该 Target | 没有配置离线 Endpoint |
| 在线监控没有数据 | 未接入 Trace、密钥错误或 Langfuse 未配置 |
| 答案解析为空 | 答案 JSONPath 与被测服务返回结构不匹配 |

## 4. 评测集（Dataset）

### 4.1 作用

离线批跑的输入集合。一条用例包含输入、参考答案、判定关键词与参考上下文。评测集可版本化、可打场景标签，同一份用例可被多次运行复用。

### 4.2 字段

| 字段 | 说明 |
|------|------|
| 评测集名称 | 最多 256 字符 |
| 版本 | 如 `v1` |
| 描述 | 测什么、适用场景 |
| 场景标签 | 如 数学 / 代码 / 中文 |
| 推荐目标类型 | `LLM_API` / `HTTP_AGENT` / `BUILTIN_AGENT` |
| 输入 | 用户输入、任务描述或 Prompt 变量，必填 |
| 参考答案 | 期望输出，可留空（依赖 Judge 或规则评分） |
| 判定关键词 | 关键词匹配评分器优先使用 |
| 参考上下文 | 供 Judge 参考的文档片段或评分说明 |

### 4.3 JSONL 导入

每行一个 JSON 对象，至少包含输入字段；可选参考答案、关键词、参考上下文。导入失败会返回失败行号与原因，已成功行不回滚。

### 4.4 规则与限制

| 规则 | 说明 |
|------|------|
| 名称唯一 | 同一空间内评测集名称唯一 |
| 分页上限 | 用例列表单页不超过 100 条 |
| 内置评测集 | 只读基线，不可删除、不可导入覆盖 |
| 导入校验 | 逐行必须是合法 JSON，缺必填字段的行会被拒绝 |
| 大批量 | 建议拆分文件，避免单次请求超时 |
| 删除 | 已被运行引用的评测集建议保留 |

### 4.5 常见问题

| 现象 | 排查 |
|------|------|
| 导入报错 | 检查是否每行一个对象、是否缺「输入」 |
| 内置评测集按钮禁用 | 内置集为只读基线，属预期 |
| 评测结果全是 0 分 | 用例缺参考答案且评分器需要参考答案 |
| 关键词评分不生效 | 评分器未选关键词匹配，或关键词字段为空 |
| 用例列表加载慢 | 单评测集用例过多，建议拆分 |

## 5. 离线评测（Offline Run）

### 5.1 作用

用固定评测集批量跑目标：给定「Target + Dataset + 用例范围 + 并发数」，平台逐条调用目标、按评分器打分、汇总总分，并保留每条用例的输出、耗时、Token 与 Trace。

### 5.2 启动表单

| 字段 | 说明 |
|------|------|
| Target | 仅列出具备离线能力的 Target |
| 评测集 | 显示版本与用例数 |
| 用例范围 | 全部 / 指定用例 |
| 并发数 | 单次运行内并发，受全局与 per-Target 限流约束 |

### 5.3 状态与规则

| 规则 | 说明 |
|------|------|
| 状态 | `PENDING` / `RUNNING` / `COMPLETED` / `FAILED` / `CANCELLED` |
| 幂等 | 相同配置短时间内重复提交会被去重，返回 `RUN_DEDUPLICATED`（409） |
| 并发隔离 | 全局并发墙 + per-Target 隔离，避免单个 Target 打满资源 |
| Judge 预算 | 三层预算：日预算 → 空间预算 → 分钟级限流；超限时降级或拒绝 |
| 单条失败 | 单条调用失败不阻塞整批，在结果中标记该条状态 |
| 版本冲突 | 同一运行并发更新返回 `RUN_VERSION_CONFLICT` |
| 删除 | 运行记录删除后不可恢复；对比前先导出 |

### 5.4 评分器类型

| 类型 | 用途 |
|------|------|
| `RULE_MATCH` | 关键词匹配（OR / AND / 正则） |
| `EXACT_MATCH` | 精确匹配（可 trim/ignoreCase） |
| `SIMILARITY` | 语义相似度 |
| `JSON_SCHEMA` | 结构化输出校验 |
| `CODE_EXECUTION` | 代码执行（语法检查 + 单元测试） |
| `LLM_AS_JUDGE` | 大模型裁判，受三层预算墙约束 |
| `TRACE_ASSERTION` | Trace 断言（span 是否存在、数量、错误、延迟、Token） |
| `TRACE_SNAPSHOT` | 与 golden span 序列对比，忽略易变字段 |
| `MANUAL` | 人工评分 |

### 5.5 关键限制

| 项 | 默认值 |
|----|--------|
| 全局并发 | 4 |
| 单次运行超时 | 7200 秒 |
| 单条用例超时 | 120 秒 |
| Judge 重试 | 2 次 |
| 每空间同时运行 | 3 |
| 每 Target 同时运行 | 2 |
| Judge 全局日 Token | 5,000,000 |
| 空间日预算占比 | 50% |

### 5.6 常见问题

| 现象 | 排查 |
|------|------|
| 启动按钮不可用 | 没有离线可用的 Target，或评测集为空 |
| 提交返回 409 | 相同配置正在运行，被去重拦截 |
| 运行长期 `RUNNING` | 目标接口慢或超时；看逐条用例状态与 Target 健康检查 |
| 总分异常低 | 评分器配置与参考答案不匹配，或 Judge 预算被拒 |
| 看不到 Token 数据 | 目标返回未提供 usage，平台按调用记录估算 |
| 重跑结果不一致 | 模型有随机性，建议固定 Temperature 对照 |

## 6. 在线监控

### 6.1 作用

面向真实生产流量：通过 Langfuse 采集 Agent 每次调用的 Trace，在平台内按 Agent、时间、traceId、成功/失败筛选查看；按策略对低质量回答自动扫描、评分与聚合，形成延迟、Token 与评分的监控视图。

### 6.2 前置条件

- 部署环境已启动 Langfuse，并配置相关环境变量。
- 目标 Agent 已「接入 Trace」，SDK 密钥已配置到被测服务。
- 空间成员可查看；策略新建/启停建议由评测负责人操作。

### 6.3 Trace 浏览器

| 功能 | 说明 |
|------|------|
| Agent 筛选 | 全部或单个 Target |
| 日期范围 | 按天筛选 |
| Trace ID 搜索 | 精确查找单条链路 |
| 状态筛选 | 全部 / 成功 / 失败 |
| 列表列 | 时间、名称、Trace ID、输入、输出、延迟、操作 |
| 查看链路 | Observation 树、模型调用、Token、耗时 |

### 6.4 在线策略

| 功能 | 说明 |
|------|------|
| 策略列表 | 名称、目标 Agent、状态、间隔、下次扫描 |
| 新建策略 | 名称、Target、扫描间隔、回看小时数、单次最多扫描、低分阈值 |
| 立即扫描 | 手动触发一次 |
| 暂停/恢复 | 切换 `ACTIVE` / `PAUSED` |
| 删除 | 不影响已产生的评分记录 |

默认扫描间隔 5 分钟，回看 24 小时，单次最多 20 条，低分阈值 60（按百分制解释，以策略配置为准）。

### 6.5 监控指标

页面顶部展示聚合指标：调用量、P50 / P95 延迟、Token 用量、自动评分分布（低分占比）。

### 6.6 规则与限制

| 规则 | 说明 |
|------|------|
| 扫描间隔 | 默认 5 分钟，可调 |
| 回看窗口 | 每次扫描回看最近 N 小时，避免重复扫历史 |
| 单次扫描上限 | 防止一次拉取过多 Trace 压垮 Langfuse |
| 低分阈值 | 低于阈值的 Trace 进入待复核集合 |
| 状态机 | 仅 `ACTIVE` / `PAUSED` |
| 数据来源 | Trace 与评分以 Langfuse 为准，平台不重复存储原始链路 |
| 上游继承 | Agent 调用需携带 traceparent，traceId 与 Langfuse 绑定 |
| 保留策略 | 由 Langfuse 项目配置决定 |

### 6.7 常见问题

| 现象 | 排查 |
|------|------|
| Trace 浏览器为空 | Agent 未接入 Trace、密钥错误或 Langfuse 不可用 |
| 日期筛选无数据 | 时区与日期边界；确认 Langfuse 同一时间窗有记录 |
| 策略不扫描 | 状态为 `PAUSED`，或下次扫描时间未到 |
| 扫描重复计分 | 同一 Trace 被多个策略覆盖，按策略维度查看 |
| 延迟/Token 指标缺失 | 上游未返回 usage，或 Trace 未记录模型事件 |
