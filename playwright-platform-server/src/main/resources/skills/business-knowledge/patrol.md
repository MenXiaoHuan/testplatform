# 巡页：LLM 驱动的页面巡检

## 1. 业务定位

巡页是「不用写测试代码」的页面巡检：配置入口 URL（可追加多个补充入口），平台自动做快照、让规划模型生成探索用例、补全模型补齐未覆盖元素、按风险决定是否需要审批、执行用例并用视觉模型或规则判定页面是否正常，最后归档录屏、截图、控制台与 DOM。

一次巡页任务 = **1 个主入口 Run + N 个补充入口 Run**；每个 Run 独立 context、预算、用例与证据，共用场景配置、模型、认证与审批策略。

适合：

- 没有现成 Playwright 用例时，快速对页面做一轮探索
- 新功能上线后确认入口页关键交互是否可用
- 定时巡检核心页面，尽早发现白屏、报错、点击无响应
- 给开发提供带录屏和截图的现场证据

与「场景 + 任务」的区别：

| 维度 | UI 自动化任务 | 巡页 |
|------|---------------|------|
| 输入 | 仓库、分支、测试选择器 | 入口 URL + 补充入口（前置操作或起始地址） |
| 用例来源 | 仓库中的测试代码 | 规划模型根据各 Run 的状态快照生成 |
| 判定方式 | 测试断言 | 视觉模型 + DOM/控制台规则 |
| 审批 | 无 | 写操作/危险操作需审批，可按巡页配置自动批准 |
| 产物 | 阶段日志、Trace、视频、报告 | 用例录屏、步骤截图、控制台、DOM |

## 2. 入口与权限

- 入口：空间菜单「UI 自动化 → 巡页」。
- `OPERATOR` / `ADMIN`：创建、编辑、复制、删除巡页，维护模型配置，立即执行、审批、取消。
- `VIEWER`：只读，可查看巡页、历史与任务详情。
- 超级管理员：额外可见「模型日志」（规划/覆盖率/判定的原始上下文与输出），普通空间管理员不可见。

## 3. 巡页配置

| 项目 | 规则 |
|------|------|
| 名称 | 必填，空间内唯一，最多 128 字符 |
| 描述 | 可选，最多 512 字符 |
| 入口 URL | 必填，`http/https`，最多 2048 字符 |
| 浏览器 | `chromium` / `chrome` / `firefox` / `edge`，默认 `chromium` |
| 运行模式 | 无头 / 有头，默认无头 |
| 解析模型 | 可选，解析补充入口前置描述；留空回退规划模型 |
| 规划模型 | 必填，负责生成主入口与补充 Run 的用例 |
| 补全模型 | 可选，生成覆盖率补全用例；留空回退规划模型 |
| 判定模型 | 必填，必须支持图片输入（视觉） |
| 时长预算 | 1~60 分钟，默认 20 分钟；每个 Run 独立计时 |
| 页面文本上限 | 100~100000 字符，默认 1800 |
| 滚动扫描 | 默认开启，扫描可视区外的可交互元素 |
| 用例录屏 | 默认开启，每条用例独立录屏 |
| 认证方式 | `NONE` / `COOKIE` / `TOKEN` / `LOCAL_STORAGE` |
| 认证内容 | Cookie、Bearer Token 或 Local Storage JSON，密文保存 |
| 自动批准写操作 | 默认关闭 |
| 自动批准危险操作 | 默认关闭，删除等不可逆操作需显式开启 |
| 场景补充 | 可追加多条补充入口：操作型（前置描述）/ URL 型（起始地址），支持名称、关注点、启用开关与「一键填入示例配置」 |
| 定时 | 开启后按「每天 / 每周（多选星期）/ 每月（选择日期）/ 自定义」的时间自动创建任务；前端自动生成 6 段 Cron，无需手填 |

「复制」会打开新建弹窗并带入原配置，名称自动加「副本」，保存后生成新的巡页。

## 4. 模型配置

巡页使用独立的模型配置，不依赖知知的模型：

- 类型：OpenAI 兼容接口，需填写 Base URL、模型 ID、API Key。
- 模型按用途分为四类并分别选择：**解析**（补充前置解析）、**规划**（用例生成）、**补全**（覆盖率补全）、**判定**（视觉/规则判定）；解析与补全仅需文本能力，判定必须勾选「支持图片输入」，留空时解析/补全回退规划模型。
- 能力参数包括「支持图片输入」「支持工具调用」「支持 JSON 输出」，默认勾选；判定模型必须保留图片输入，其余按模型实际情况调整。
- API Key 加密保存；编辑时留空表示保留原 Key。
- 支持测试连通性；删除被巡页引用的模型会导致该巡页无法规划/判定，删除后需重新选择模型。

## 5. 执行链路

```
主入口：入口页快照
  → 规划用例（规划模型）
  → 覆盖率补全（补全模型）
  → 风险判断与审批（可选）
  → 逐用例执行（独立 context + 录屏）
  → 视觉/规则判定（判定模型或降级）
  → 归档证据与统计

补充入口：前置解析（解析模型）→ 执行前置 → 状态快照
  → 规划 / 补全 / 执行 / 判定（与主入口并发，独立 Run）
```

- 快照：读取入口页或补充状态的可交互元素、可见文本并截图；后续规划与覆盖率以各自 Run 的快照为基准。
- 规划：生成「意图 + 期望 + 步骤」的用例；动作有白名单，单用例最多 8 步。
- 覆盖率：统计各 Run 快照中可交互元素被用例覆盖的比例，再汇总。
- 补充入口：前置解析优先确定性文案匹配，失败才调用解析模型；解析失败或执行时元素消失，该 Run 标记 `UNREACHABLE`，用例 `SKIP`，不影响其他 Run。
- 审批：含写/危险操作的用例需要授权；只读用例自动通过。补充入口前置含写/危险动作时，审批前不执行前置、不快照、不规划。
- 执行：每条用例独立上下文，结束后额外等待 3 秒再结束录制，保留收尾画面；元素操作/断言前先把目标滚到视口中央，每步留存截图（元素操作取操作前画面，失败额外取失败画面）。
- 判定：判定模型结合截图与页面信息给出通过/失败和发现项；模型不可用时退回 DOM/控制台规则。

## 6. 任务状态与阶段

| 状态 | 前端文案 | 含义 |
|------|----------|------|
| `QUEUED` | 待执行 | 已创建，等待执行 |
| `RUNNING` | 执行中 | 正在快照、规划、执行或判定 |
| `WAITING_APPROVAL` | 待审批 | 存在写/认证/危险用例或写操作前置，等待人工授权 |
| `COMPLETED` | 已完成 | 执行结束并完成判定，可能带降级 |
| `FAILED` | 失败 | 准备/快照/执行失败，或服务重启恢复判定失败 |
| `CANCELED` | 已取消 | 用户取消并已停止 |

阶段：

`PREPARING`（准备环境）→ `SNAPSHOTTING`（入口页 / 补充状态快照）→ `PLANNING`（生成用例与覆盖率补全）→ `WAITING_APPROVAL`（可选）→ `EXECUTING`（执行用例）→ `JUDGING`（判定）→ `FINISHED`（归档）。

补充入口 Run 额外包含 `RESOLVING`（前置解析）→ 执行前置 → `SNAPSHOTTING`（状态快照）；主任务需等待所有补充 Run 结束后才收尾。补充入口与主入口共用任务状态机，通过 `parent_task_id` + `entry_type(MAIN/SUPPLEMENT)` 关联。

## 7. 预算与降级

| 项 | 规则 |
|----|------|
| 时长预算 | 默认 20 分钟；超时停止继续执行，已产生的用例结果仍归档 |
| Token 消耗 | 仅统计展示，不设任务级上限；单次输出由模型配置 maxTokens 约束 |
| 时长耗尽 | 任务标记「降级」并记录停止原因；判定退回规则 |
| 模型调用 | 流式读取：空闲超时 120 秒、单次调用总时长上限 1800 秒；仅网络类失败重试，最多 2 次 |
| 环境与页面 | 依赖安装/入口快照最多 300 秒；页面加载 20 秒；单步动作 5 秒 |
| 规划输出 | 单次输出上限取模型配置 maxTokens（8k/16k/32k/64k） |
| 判定输出 | 单次输出上限取模型配置 maxTokens（8k/16k/32k/64k） |

降级表示任务已完成，但部分模型环节没有按预期工作：未配置模型、Token 不足、调用失败或输出无法解析。降级任务仍会给结果，但可信度低于正常判定。任务概览会把失败归一成「原因 + 解决建议」：超时/截断/推理耗尽给出当前 maxTokens 与建议升档，已是最高档则建议换非推理模型；余额不足、Key 无效、模型不存在、限流、网络问题分别给出对应处理动作。

## 8. 风险与审批

- 风险等级从低到高：`READ`（只读）< `WRITE`（写）< `AUTH`（认证/权限）< `DESTRUCTIVE`（不可逆）。
- 用例风险取步骤中最高风险。
- 只有只读用例时任务自动继续；存在写/认证/危险用例时进入「待审批」。
- 补充入口前置描述同样做风险判定：填写/输入/按键，或命中「保存、提交、新增、编辑、登录、删除、支付、退款」等关键字时按 `WRITE` / `DESTRUCTIVE` 处理。
- 巡检开启「自动批准写操作」「自动批准危险操作」，减少人工审批；所有 Run 的风险合并为一次审批，子任务不单独审批。
- 审批时可选择：
  - **批准并执行**：授权写操作；「允许危险操作」开关打开时才授权不可逆操作。
  - **全部拒绝（仅只读）**：只执行只读用例。
- 审批记录审批人、审批时间与授权的用例；审批后继续执行，不需要重新创建任务。

## 9. 判定、发现项与证据

- 用例执行失败（执行状态 `FAILED`）直接判失败，并生成 P0 交互发现项。
- 模型判定失败会给出原因与发现项；发现项严重级别为 `P0` / `P1` / `P2`，类型包括阻断、交互、展示、文案、一致性。
- 判定提示词会附上控制台报错原文（`pageerror` / `error` / `warning`，相同文案合并计数，按预算截断），
  由模型判断报错与用例是否相关；控制台错误数量只作为兜底统计，无关噪音（favicon/图片 404、统计脚本、跨域第三方资源）不作为失败依据。
- 模型不可用时的规则判定（此时只用控制台错误数量兜底）：
  - 有失败步骤 → 失败，P0；
  - 控制台有错误 → 失败，P1；
  - 其他 → 通过。
- 证据包括：各 Run 的状态快照、每条用例的录屏（含补充前置过程）、步骤截图、最终截图、控制台日志、DOM。
- 任务详情用例按 Run 分组展示（主入口、`[补充] 名称`），组头显示状态、覆盖率、耗时、Token。
- 任务详情「模型日志」仅超级管理员可见，按规划 / 覆盖率补全 / 前置解析 / 判定四个阶段记录模型、状态、Token、耗时、错误与原始上下文/输出。

## 10. 定时与保留

| 项 | 规则 |
|----|------|
| 配置方式 | 前端选择「每天 / 每周（多选星期）/ 每月（选择日期）/ 自定义」，保存时自动转换为 6 段 Cron |
| 调度扫描 | 每 60 秒扫描到期巡页 |
| 跳过条件 | 未配置模型、同巡页已有活动任务、平台并发已满 |
| 下次运行 | 无论本次是否创建任务都会推进，避免重复触发 |
| 平台并发 | 默认 10 个巡页任务并行，并行已满时手动执行排队（默认最多 100 个）；定时执行跳过 |
| 取消 | 协作式：置取消标记，当前步骤结束后停止；没有活跃执行线程（重启/线程丢失）时直接落库为已取消 |
| 服务重启 | 中断的 `QUEUED`/`RUNNING` 标记失败；「待审批」任务保留；每 60 秒兜底扫描超预算+10 分钟仍无线程的脏运行任务 |
| 保留 | 默认 90 天；每天 02:30 清理到期任务与全部证据 |
| 删除巡页 | 有活动任务时禁止删除；删除会清理历史任务与证据 |

## 11. 典型流程

### 11.1 首次配置并执行

1. 「巡页 → 模型配置」新建规划模型与判定模型，判定模型勾选视觉能力并测试连通性；按需再建解析/补全模型。
2. 新建巡页：填入口 URL，选择解析/规划/补全/判定模型，按需调整预算、认证与定时。
3. 如需覆盖入口页之外的状态，在「场景补充」中新增补充入口；操作型写前置描述，URL 型写起始地址。
4. 点「执行」，在历史中观察任务状态。
5. 若进入「待审批」，查看待执行的写/危险用例（含补充前置）后选择批准或只读执行。
6. 完成后查看各 Run 的用例、发现项与录屏。

### 11.2 定时巡检

1. 开启定时并选择执行频率与时间（如每天 02:30），保存时自动生成 Cron。
2. 确认模型可用、预算合理。
3. 次日从「历史」查看任务；没有任务时检查跳过条件。

### 11.3 排查降级任务

1. 看任务概览的结果说明与降级标记。
2. 超级管理员打开「模型日志」，确认是规划、覆盖率、前置解析还是判定阶段降级。
3. 时长不足 → 调大时长预算或缩小巡检范围；补充入口规划偏离 → 优化「关注点」；调用失败 → 先在模型配置中测试连通性。

## 12. 常见问题

| 现象 | 排查 |
|------|------|
| 执行按钮提示未配置模型 | 巡页必须选择规划模型与判定模型；解析/补全留空时回退规划模型 |
| 提示已有任务在执行 | 同一巡页同时只允许一个活动任务 |
| 提示队列已满 | 平台默认 10 个并行 + 100 个排队 |
| 一直停在执行中 | 看当前阶段：准备/快照多为环境或网络；执行阶段看用例与录屏 |
| 判定全是规则判定 | 模型未配置、调用失败、Token 不足或输出无法解析 |
| 覆盖率偏低 | 元素在折叠区或 iframe；开启滚动扫描，必要时调大页面文本上限 |
| 录屏缺失 | 巡页关闭了用例录屏，或用例未开始执行 |
| 产物下载过期 | 预签名 URL 过期，重新打开任务详情 |
| 补充入口没执行 | 入口是否启用；前置是否解析失败（`UNREACHABLE`）；URL 型是否同主机；写操作前置是否停在待审批 |
| 补充入口覆盖偏低 | 「关注点」是否为空或过于笼统；可先「解析预览」确认前置进入的目标状态 |
| 定时没有触发 | 定时是否开启、执行时间是否保存、是否被活动任务/并发跳过 |
| 历史任务消失 | 任务按 90 天保留，到期自动清理 |
| 看不到模型日志 | 仅超级管理员可见 |
| 删除巡页失败 | 仍有活动任务，先取消或等待结束 |
