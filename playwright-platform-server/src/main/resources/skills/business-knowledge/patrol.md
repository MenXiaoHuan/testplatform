# 巡页：LLM 驱动的页面巡检

## 1. 业务定位

巡页是「不用写测试代码」的页面巡检：配置入口 URL 和任务描述，平台自动做入口页快照、让规划模型生成探索用例、按风险决定是否需要审批、执行用例并用视觉模型或规则判定页面是否正常，最后归档录屏、截图、控制台与 DOM。

适合：

- 没有现成 Playwright 用例时，快速对页面做一轮探索
- 新功能上线后确认入口页关键交互是否可用
- 定时巡检核心页面，尽早发现白屏、报错、点击无响应
- 给开发提供带录屏和截图的现场证据

与「场景 + 任务」的区别：

| 维度 | UI 自动化任务 | 巡页 |
|------|---------------|------|
| 输入 | 仓库、分支、测试选择器 | 单个入口 URL + 任务描述 |
| 用例来源 | 仓库中的测试代码 | 规划模型根据页面快照生成 |
| 判定方式 | 测试断言 | 视觉模型 + DOM/控制台规则 |
| 审批 | 无 | 写操作/危险操作需审批，可按巡页配置自动批准 |
| 产物 | 阶段日志、Trace、视频、报告 | 用例录屏、步骤截图、控制台、DOM |

## 2. 入口与权限

- 入口：空间菜单「UI 自动化 → 巡页」。
- `OPERATOR` / `ADMIN`：创建、编辑、复制、删除巡页，维护模型配置，立即执行、审批、取消。
- `VIEWER`：只读，可查看巡页、历史与任务详情。
- 超级管理员：额外可见「模型日志」（规划/覆盖率/判定的原始上下文与输出），普通空间管理员不可见。

## 3. 巡页配置

| 项目 | 规则 |
|------|------|
| 名称 | 必填，空间内唯一，最多 128 字符 |
| 描述 | 可选，最多 512 字符 |
| 入口 URL | 必填，`http/https`，最多 2048 字符 |
| 浏览器 | `chromium` / `chrome` / `firefox` / `edge`，默认 `chromium` |
| 运行模式 | 无头 / 有头，默认无头 |
| 任务描述 | 告诉模型本次关注点，最多 1024 字符 |
| 规划模型 | 必填，负责生成用例 |
| 判定模型 | 必填，必须支持图片输入（视觉） |
| 时长预算 | 1~60 分钟，默认 15 分钟 |
| Token 预算 | 10000~1000000，默认 300000 |
| 页面文本上限 | 100~100000 字符，默认 1800 |
| 滚动扫描 | 默认开启，扫描可视区外的可交互元素 |
| 录制视频 | 默认开启，每条用例独立录屏 |
| 认证方式 | `NONE` / `COOKIE` / `TOKEN` / `LOCAL_STORAGE` |
| 认证内容 | Cookie、Bearer Token 或 Local Storage JSON，密文保存 |
| 自动批准写操作 | 默认关闭 |
| 自动批准危险操作 | 默认关闭，删除等不可逆操作需显式开启 |
| 定时 | 开启后按 Cron 自动创建任务；Cron 为 Spring 6 段表达式 |

「复制」会打开新建弹窗并带入原配置，名称自动加「副本」，保存后生成新的巡页。

## 4. 模型配置

巡页使用独立的模型配置，不依赖知知的模型：

- 类型：OpenAI 兼容接口，需填写 Base URL、模型 ID、API Key。
- 规划模型只需文本能力；判定模型必须勾选「支持图片输入」。
- 能力参数包括「支持图片输入」「支持工具调用」「支持 JSON 输出」，默认勾选；判定模型必须保留图片输入，其余按模型实际情况调整。
- API Key 加密保存；编辑时留空表示保留原 Key。
- 支持测试连通性；删除被巡页引用的模型会导致该巡页无法规划/判定，删除后需重新选择模型。

## 5. 执行链路

```
入口页快照
  → 规划用例（LLM）
  → 覆盖率补全（可再次调用规划模型）
  → 风险判断与审批（可选）
  → 逐用例执行（独立浏览器上下文 + 录屏）
  → 视觉/规则判定（LLM 或降级）
  → 归档证据与统计
```

- 快照：读取入口页可交互元素、可见文本并截图；后续规划与覆盖率都以入口页为基准。
- 规划：生成「意图 + 期望 + 步骤」的用例；动作有白名单，单用例最多 8 步。
- 覆盖率：统计入口页可交互元素被用例覆盖的比例。
- 审批：含写/危险操作的用例需要授权；只读用例自动通过。
- 执行：每条用例独立上下文，结束后额外等待 3 秒再结束录制，保留收尾画面。
- 判定：判定模型结合截图与页面信息给出通过/失败和发现项；模型不可用时退回 DOM/控制台规则。

## 6. 任务状态与阶段

| 状态 | 前端文案 | 含义 |
|------|----------|------|
| `QUEUED` | 待执行 | 已创建，等待执行 |
| `RUNNING` | 执行中 | 正在快照、规划、执行或判定 |
| `WAITING_APPROVAL` | 待审批 | 用例已生成，等待人工授权 |
| `COMPLETED` | 已完成 | 执行结束并完成判定，可能带降级 |
| `FAILED` | 失败 | 准备/快照/执行失败，或服务重启恢复判定失败 |
| `CANCELED` | 已取消 | 用户取消并已停止 |

阶段：

`PREPARING`（准备环境）→ `SNAPSHOTTING`（入口页快照）→ `PLANNING`（生成用例与覆盖率补全）→ `WAITING_APPROVAL`（可选）→ `EXECUTING`（执行用例）→ `JUDGING`（判定）→ `FINISHED`（归档）。

## 7. 预算与降级

| 项 | 规则 |
|----|------|
| 时长预算 | 默认 15 分钟；超时停止继续执行，已产生的用例结果仍归档 |
| Token 预算 | 默认 300000；规划、覆盖率补全、判定共同消耗 |
| 预算耗尽 | 任务标记「降级」并记录停止原因；判定退回规则 |
| 模型调用 | 单次超时 90 秒；最多尝试 2 次 |
| 环境与页面 | 依赖安装/入口快照最多 300 秒；页面加载 20 秒；单步动作 5 秒 |
| 规划输出 | 单次最多约 4500 Token |
| 判定输出 | 单次最多约 1800 Token |

降级表示任务已完成，但部分模型环节没有按预期工作：未配置模型、Token 不足、调用失败或输出无法解析。降级任务仍会给结果，但可信度低于正常判定。

## 8. 风险与审批

- 风险等级从低到高：`READ`（只读）< `WRITE`（写）< `AUTH`（认证/权限）< `DESTRUCTIVE`（不可逆）。
- 用例风险取步骤中最高风险。
- 只有只读用例时任务自动继续；存在写/认证/危险用例时进入「待审批」。
- 巡页可开启「自动批准写操作」「自动批准危险操作」，减少人工审批。
- 审批时可选择：
  - **批准并执行**：授权写操作；「允许危险操作」开关打开时才授权不可逆操作。
  - **全部拒绝（仅只读）**：只执行只读用例。
- 审批记录审批人、审批时间与授权的用例；审批后继续执行，不需要重新创建任务。

## 9. 判定、发现项与证据

- 用例执行失败（执行状态 `FAILED`）直接判失败，并生成 P0 交互发现项。
- 模型判定失败会给出原因与发现项；发现项严重级别为 `P0` / `P1` / `P2`，类型包括阻断、交互、展示、文案、一致性。
- 模型不可用时的规则判定：
  - 有失败步骤 → 失败，P0；
  - 控制台有错误 → 失败，P1；
  - 其他 → 通过。
- 证据包括：入口页快照、每条用例的录屏、步骤截图、最终截图、控制台日志、DOM。
- 任务详情「模型日志」仅超级管理员可见，按规划 / 覆盖率补全 / 判定三个阶段记录模型、状态、Token、耗时、错误与原始上下文/输出。

## 10. 定时与保留

| 项 | 规则 |
|----|------|
| 调度扫描 | 每 60 秒扫描到期巡页 |
| 跳过条件 | 未配置模型、同巡页已有活动任务、平台并发已满 |
| 下次运行 | 无论本次是否创建任务都会推进，避免重复触发 |
| 平台并发 | 默认 2 个巡页任务并行 |
| 取消 | 协作式：置取消标记，当前步骤结束后停止 |
| 服务重启 | 中断的活动任务标记失败；「待审批」任务保留 |
| 保留 | 默认 90 天；每天 02:30 清理到期任务与全部证据 |
| 删除巡页 | 有活动任务时禁止删除；删除会清理历史任务与证据 |

## 11. 典型流程

### 11.1 首次配置并执行

1. 「巡页 → 模型配置」新建规划模型与判定模型，判定模型勾选视觉能力并测试连通性。
2. 新建巡页：填入口 URL、任务描述，选择两个模型，按需调整预算与认证。
3. 点「执行」，在历史中观察任务状态。
4. 若进入「待审批」，查看待执行的写/危险用例后选择批准或只读执行。
5. 完成后查看用例、发现项与录屏。

### 11.2 定时巡检

1. 开启定时并填写 Cron（如每天 02:30 为 `0 30 2 * * *`）。
2. 确认模型可用、预算合理。
3. 次日从「历史」查看任务；没有任务时检查跳过条件。

### 11.3 排查降级任务

1. 看任务概览的结果说明与降级标记。
2. 超级管理员打开「模型日志」，确认是规划、覆盖率还是判定阶段降级。
3. Token 不足 → 调大预算或收敛任务描述；调用失败 → 先在模型配置中测试连通性。

## 12. 常见问题

| 现象 | 排查 |
|------|------|
| 执行按钮提示未配置模型 | 巡页必须选择规划模型与判定模型 |
| 提示已有任务在执行 | 同一巡页同时只允许一个活动任务 |
| 提示并发已满 | 平台默认 2 个并行巡页任务 |
| 一直停在执行中 | 看当前阶段：准备/快照多为环境或网络；执行阶段看用例与录屏 |
| 判定全是规则判定 | 模型未配置、调用失败、Token 不足或输出无法解析 |
| 覆盖率偏低 | 元素在折叠区或 iframe；开启滚动扫描，必要时调大页面文本上限 |
| 录屏缺失 | 巡页关闭了录制视频，或用例未开始执行 |
| 产物下载过期 | 预签名 URL 过期，重新打开任务详情 |
| 定时没有触发 | Cron 是否 6 段、定时是否开启、是否被跳过 |
| 历史任务消失 | 任务按 90 天保留，到期自动清理 |
| 看不到模型日志 | 仅超级管理员可见 |
| 删除巡页失败 | 仍有活动任务，先取消或等待结束 |
