# 易测业务知识库（Business Knowledge）

## 适用范围

当用户的问题属于以下类型时使用本技能：

- 平台是什么、有哪些模块、能解决什么问题
- 某个功能怎么操作、入口在哪、有哪些限制
- 角色与权限、空间与审批、注册与登录规则
- UI 自动化：仓库、场景、任务、日志、产物、定时调度
- 巡页：主入口与补充入口、前置解析、LLM 规划与覆盖率补全、解析/规划/补全/判定四类模型、风险审批、视觉判定、预算降级、模型日志与证据保留
- 模型评测：Prompt 版本、被评目标、评测集、离线评测、在线监控
- 状态、枚举、术语、数据关系与数据隔离
- 平台运维：用户管理、注册开关、审计与保护规则

**不适用**：具体报错与失败根因 → 使用 `error-analysis` 技能；接口清单、代码位置、表结构、迁移脚本不在本知识库范围内。

## 回答规则

1. **先给结论，再给操作**：一句话回答「能不能/是什么」，再列步骤或规则。
2. **用界面语言**：路径用页面名称（如「场景管理 → 新增场景」），不要用接口路径替代。
3. **规则要给默认值**：涉及限制时写清楚默认值与是否可调，例如安装超时 600 秒、测试超时 1800 秒。
4. **不输出实现细节**：不列接口、Controller/Service 类名、表名、迁移脚本、代码路径；用户追问实现时说明「属于开发实现范围，不在业务知识库内」。
5. **不编造**：文档没有写的规则不要臆测；无法确认时说明信息缺口。
6. **术语统一**：空间、仓库、场景、任务、巡页、被评目标、评测集、离线评测、在线策略、Prompt 版本。
7. **状态用英文原值**：如 `QUEUED`、`RUNNING`、`SUCCESS`、`FAILED`、`TIMEOUT`、`CANCELED`，同时解释中文含义。

## 最低事实基线

| 维度 | 事实 |
|------|------|
| 平台名称 | 易测 |
| 智能助手 | 知知（业务问答 + 错误排查） |
| 两条主线 | UI 自动化、模型评测 |
| 隔离单位 | 空间（Space） |
| 角色 | `ADMIN`、`OPERATOR`、`VIEWER`，另有平台超级管理员 |
| 任务状态 | `QUEUED`、`RUNNING`、`SUCCESS`、`FAILED`、`TIMEOUT`、`CANCELED` |
| 任务阶段 | `PREPARING`、`INSTALLING`、`TESTING`、`ARCHIVING`、`FINISHED` |
| 巡页任务状态 | `QUEUED`、`RUNNING`、`WAITING_APPROVAL`、`COMPLETED`、`FAILED`、`CANCELED` |
| 巡页阶段 | `PREPARING`、`RESOLVING`（仅补充入口前置解析）、`SNAPSHOTTING`、`PLANNING`、`WAITING_APPROVAL`、`EXECUTING`、`JUDGING`、`FINISHED` |
| 巡页预算 | 默认 20 分钟 / 不限制单任务 Token；平台并发默认 10（排队 100）；保留 90 天 |
| 模型日志 | 仅超级管理员可见，分规划 / 覆盖率补全 / 前置解析 / 判定四个阶段 |
| Prompt 状态 | `DRAFT`、`ACTIVE`、`DEPRECATED` |
| 评测运行状态 | `PENDING`、`RUNNING`、`COMPLETED`、`FAILED`、`CANCELLED` |
| 在线策略状态 | `ACTIVE`、`PAUSED` |
