# 业务功能知识

## 核心功能模块

### 1. 用户账户与个人信息
- **注册/登录**：用户名 + 密码注册，密码使用 RSA 加密传输
- **昵称修改**：注册后可随时修改昵称，展示在对话框、侧边栏等位置
- **头像上传**：支持上传自定义头像（图片），未设置头像时显示昵称首字母
- **个人信息展示**：对话框标题栏显示「昵称 · 空间名 · AI 驱动」

### 2. 空间管理（Space）
- 创建/加入空间，实现多租户数据隔离
- 空间成员角色管理（管理员/开发者/观察者）
- 访问申请审批流程

### 3. 权限体系
- **RBAC 模型**：基于角色的访问控制
- **空间级权限**：每个空间独立的成员和权限设置
- **角色定义**：
  - 管理员：完整控制权，成员管理、配置删除
  - 开发者：创建/编辑场景、触发执行、查看日志
  - 观察者：只读权限，仅可查看结果
- **操作鉴权**：后端每次 API 调用校验用户角色和空间归属

### 4. 审批流程
- **空间加入审批**：用户申请加入空间 → 管理员审批 → 通过/拒绝
- **审批状态**：PENDING（待审批）、APPROVED（已通过）、REJECTED（已拒绝）
- **审批通知**：审批结果通过系统通知告知申请人

### 5. 测试仓库管理（Repository）
- 关联 Git 仓库（HTTPS/SSH）
- 配置默认分支、测试目录、运行命令模板
- 启用/禁用仓库

### 6. 测试场景管理（Scene）
- 创建场景：关联仓库 + 选择器（CSS/XPath/Text/Regex）+ 浏览器
- 配置环境变量（envJson）：API 地址、Token、超时等
- 定时调度：Cron 表达式配置
- 手动触发执行

### 7. 任务执行与调度事件
```
用户触发 → 入队(QUEUED) → Runner 领取 → 执行(RUNNING) → 完成(COMPLETED/FAILED)
                                        │
                                        ├── INSTALL 阶段：安装依赖
                                        ├── RUN 阶段：执行 Playwright
                                        └── REPORT 阶段：生成报告
```
- **触发方式**：手动触发 / 定时调度 / API 调用
- **执行模式**：本地 / Docker 容器
- **结果统计**：通过/失败/跳过用例数
- **日志存储**：MinIO 对象存储
- **调度事件**：每次执行产生调度事件记录，包含：
  - 触发时间、触发方式（手动/定时/API）
  - 执行状态流转：QUEUED → RUNNING → COMPLETED/FAILED
  - 每个阶段的耗时、日志、结果
  - 关联场景 ID、仓库 ID、空间 ID

### 8. AI 智能助手
- 入口：右下角浮动按钮 → 打开对话框
- 功能：故障排查、业务咨询、任务分析、链路回溯
- 流式响应：SSE 打字机效果
- 对话历史：会话持久化 + 上下文压缩
- 工具调用：自动调用 TaskTool / SceneTool / LogPreprocessingTool / TraceQueryTool
- 全链路追踪：每次对话生成 traceId，90 天内可通过 TraceQueryTool 查询完整调用链路

## API 端点速查

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/ai/chat` | 同步 AI 对话 |
| POST | `/api/ai/chat/stream` | 流式 AI 对话（SSE） |
| DELETE | `/api/ai/session/{sessionId}` | 清理会话 |
| GET | `/api/ai/sessions/count` | 活跃会话数 |
| PUT | `/api/user/profile` | 更新用户昵称 |
| POST | `/api/user/avatar` | 上传用户头像 |
| POST | `/api/space/{spaceId}/apply` | 申请加入空间 |
| PUT | `/api/space/access-requests/{id}/approve` | 审批通过 |
| PUT | `/api/space/access-requests/{id}/reject` | 审批拒绝 |

## 常见操作指南

### 如何排查一个失败的任务？
1. 获取任务 ID（从场景页面或任务列表）
2. 告诉 AI 助手：「帮我分析任务 {taskId} 的失败原因」
3. AI 会自动调用 getTask + analyzeLogs
4. 根据 AI 给出的故障类型查阅对应的 SOP

### 如何查询 Agent 调用链路？
1. 从 AI 回答底部复制 traceId
2. 告诉 AI 助手：「查询 traceId: {traceId}」
3. AI 会调用 queryTrace(traceId) 返回完整链路
4. 包含所有阶段日志、耗时、工具调用信息

### 如何修改个人信息？
1. 点击右上角用户头像
2. 在个人资料中修改昵称或上传头像
3. 保存后立即生效

### 如何申请加入空间？
1. 点击「加入空间」按钮
2. 输入空间 ID 或选择空间
3. 提交申请 → 等待管理员审批
4. 审批通过后自动加入空间

### 如何配置定时任务？
1. 创建/编辑场景
2. 开启「定时调度」开关
3. 填写 Cron 表达式（如 `0 0 2 * * ?` 表示每天凌晨 2 点）
4. 保存后场景会按计划自动执行

### 如何查看执行日志？
1. 在任务详情页查看各阶段日志预览
2. 完整日志存储在 MinIO，可通过 logUrl 下载
3. AI 助手可通过 analyzeLogs 直接分析日志摘要
