# 平台运维：用户管理与注册开关

## 1. 业务定位

平台运维面向**平台级**管理，而不是单个空间。超级管理员在这里管理全平台账号（查看、编辑、重置密码、删除），并控制登录页是否开放自助注册。

注册开关从配置文件迁移到数据库后，修改即时生效，无需重启服务。

适用场景：

- 关闭自助注册，改为管理员统一建号
- 排查账号异常（禁用、重置密码）
- 清理离职人员账号
- 临时开放注册让新成员自助注册

## 2. 权限

| 项 | 说明 |
|----|------|
| 可见范围 | 仅超级管理员可见「平台运维 → 用户管理」 |
| 双重校验 | 菜单、路由与后端接口均校验超级管理员身份，非超管返回无权限 |
| 身份来源 | 由用户账号上的超级管理员标记决定 |
| 普通空间 `ADMIN` | 即使管理某个空间，也看不到用户管理 |

## 3. 功能说明

入口在当前空间菜单，但操作对象是**全平台用户**。

| 功能 | 说明 |
|------|------|
| 用户列表 | 列：ID、用户（头像 + 昵称 + 用户名）、角色、状态、注册时间、更新时间 |
| 搜索 | 按用户名或昵称模糊搜索，回车即查询 |
| 允许自助注册 | 右上角开关；切换前弹出确认，展示「当前状态 → 切换后」 |
| 查看用户 | 头像、昵称、用户名、角色、状态、最近空间、时间信息 |
| 编辑用户 | 修改昵称（≤10 字符）与启用状态 |
| 重置密码 | 输入新密码，前端 RSA 加密后提交 |
| 删除用户 | 清理空间成员关系与登录会话 |

## 4. 关键规则与保护

| 规则 | 说明 |
|------|------|
| 仅超管 | 前后端双重校验 |
| 昵称 | 最多 10 个字符，全平台唯一 |
| 密码 | 至少 8 位，且包含字母和数字；传输前 RSA 加密 |
| 不能禁用超管 | 返回「不能禁用超级管理员账号」 |
| 不能禁用自己 | 当前登录账号不可禁用 |
| 不能删除超管 | 返回「不能删除超级管理员账号」 |
| 不能删除自己 | 当前登录账号不可删除 |
| 删除影响 | 一并清理空间成员关系与登录会话，不可恢复 |
| 注册开关 | 写入数据库后即时生效；`.env` 中的 `PLATFORM_REGISTRATION_ENABLED` 仅作默认值 |
| 审计 | 编辑、重置密码、删除、切换注册开关均写入平台审计日志 |

## 5. 典型流程：关闭自助注册并统一建号

1. 超管进入「用户管理」，把「允许自助注册」关闭，确认弹窗中核对状态变化。
2. 登录页刷新后不再展示注册入口（已登录用户不受影响）。
3. 新成员由超管创建后通知本人登录，或临时开启注册让其自助注册。
4. 离职人员用「更多 → 删除」清理，确认其空间关系与会话被移除。

## 6. 常见问题

| 现象 | 排查 |
|------|------|
| 菜单里没有「用户管理」 | 当前账号不是超级管理员 |
| 开关点了但登录页仍有注册入口 | 确认保存成功；刷新登录页；检查平台设置值 |
| 无法禁用某账号 | 该账号是超管或就是当前登录账号 |
| 无法删除某账号 | 同上，超管与自身账号均受保护 |
| 重置密码后旧密码仍可登录 | 旧会话仍有效；让用户重新登录或清理会话 |
| 角色标签显示异常 | 角色列固定宽度 + 标签不换行，属界面约定 |
