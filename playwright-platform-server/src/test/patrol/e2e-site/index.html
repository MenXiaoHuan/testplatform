UI 场景导航

每个页面覆盖一类场景，既有简单控件，也有多层弹层、Shadow DOM、同源 iframe 与异步异常状态。

表单场景 输入、校验、复选框、单选框、开关、原生/自定义下拉、多选、日期、时间、级联、树选择、评分、滑块、标签输入、穿梭框、分步向导、登录注册。 弹层场景 基础弹窗、三层嵌套弹窗、动态创建弹窗、抽屉、抽屉内弹窗、下拉子菜单、右键菜单、Tooltip、Popover、确认框、Toast、图片预览、命令面板。 数据展示 可排序/筛选/分页表格、行展开、批量选择、树形表格、Tabs、折叠面板、轮播、时间线、进度条、空状态、骨架屏。 复杂交互 拖拽排序、跨列表拖拽、可调节分栏、无限滚动、同源 iframe 表单、开放 Shadow DOM、内容可编辑、键盘快捷键。 异步与异常 加载中、慢请求、500 错误、401 未授权、重试、空数据、离线提示、轮询、表单提交成功/失败。 订单列表 简单静态表格与链接跳转，用于验证最基础的页面感知与跳转。
